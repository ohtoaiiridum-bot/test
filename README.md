# 游戏列表

把 `GameList.md` 转成可在浏览器里管理的 HTML 清单。

## 使用

用浏览器打开 `index.html`，或在本目录启动一个静态服务：

```bash
python3 -m http.server 4173
```

然后访问 http://localhost:4173 。

数据保存在浏览器 `localStorage`，刷新不会丢。需要备份时点「导出 Markdown」或「导出 JSON」。

## 功能

- 按「计划中 / 好玩 / 不好玩」分列查看
- 添加、编辑、删除、搜索
- 拖拽或按钮移动分类
- **重复项单独成区**：同名游戏会从主列表抽出来，可「只留这条」或整组去重
- 名字很接近但不完全相同的条目会列在「可能重复」里
- 导入 / 导出 JSON，导出 Markdown，恢复最初的原文清单
